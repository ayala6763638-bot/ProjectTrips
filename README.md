" מערכת לניהול טיול שנתי-"בנות משה
מערכת המיועדת עבור מורות בית הספר "בנות משה" שנותנת אפשרות:
ניהול כיתה
רישום תלמידה 
ומעקב צמוד לאורך כל הטיול
שזה כולל גם התראות אוטמטיות בשעה שהתלמידה חרגה מהמרחק שלה מהמורה

# טכנולוגיות שהשתמשתי בהם לאורך הפרויקט:
-Client:
     React, ספריית: React LeafLet-עבור שימוש במפות ,Socket.io-client,Aaxios.

-Server:
     Node.js,Express,Socket.io.

-סימולטור: 
    Node.js,Express,Socket.io.

-DB:
    MongoDB.

# דרישות מקדימות להרצת הפרויקט:
-Node.js במחשב
-MongoDB/SQL אם צריך.

# הוראות התקנה והרצה לפרויקט

# התקנת תלויות
הרץ בתקיית Server ו Client:

npm install

--Server:
cd school-trip-app
nodemon index.js

--Client:
cd scool-trip-ui
cd my-school-app
npm run dev

---Simulator:
cd simulator
node simulator.js
